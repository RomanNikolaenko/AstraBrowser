Листи Astra Browser — світла й темна тема

01-confirm-signup.html — Код підтвердження Astra Browser

Надсилає Supabase — шаблон «Confirm sign up»

02-welcome.html — Ласкаво просимо до Astra Browser

Надсилає наш сервер — одразу після того, як пошту підтвердили кодом, чи після першого входу через Google

03-reset-password.html — Відновлення пароля Astra Browser

Надсилає Supabase — шаблон «Reset password»

04-password-changed.html — Пароль Astra Browser змінено

Надсилає Supabase — шаблон «Password changed (Security notifications)»

05-new-sign-in.html — Новий вхід в Astra Browser

Надсилає наш сервер — після входу з незнайомого місця (IP) на вже знайомому комп’ютері

06-sign-in-code.html — Ваш код входу в Astra Browser

Надсилає Supabase — шаблон «Magic link or OTP»

07-new-device.html — Новий пристрій синхронізується з Astra Browser

Надсилає наш сервер — після першого входу на комп’ютері, де цей обліковий запис ще не входив

08-email-change.html — Підтвердіть зміну пошти Astra Browser

Надсилає Supabase — шаблон «Change email address»

09-delete-account.html — Підтвердіть видалення облікового запису Astra Browser

Надсилає не надсилається — видалення облікового запису підтверджується паролем (supabase/account.sql)

10-account-deleted.html — Обліковий запис Astra Browser видалено

Надсилає наш сервер — одразу після видалення облікового запису

11-reauthentication.html — Підтвердіть дію в Astra Browser

Надсилає Supabase — шаблон «Reauthentication»
